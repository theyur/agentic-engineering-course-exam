# PageAdminFeedback

Admin · Feedback tab: filter (Open · Resolved · All), search, a table of messages and the opened message below.

- Table: date, topic, sender email, message (one line, cut with …), Tag Open / Resolved, action Mark resolved / Reopen. The selected row is highlighted.
- Detail card: full message, an internal admin note, Mark resolved. There is no reply-by-email in version 1.
