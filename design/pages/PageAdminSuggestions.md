# PageAdminSuggestions

Admin · Suggestions tab: a queue on the left, the review form on the right.

- Left: suggestions oldest first (`ht-select-row`, current one highlighted). Empty: EmptyState "No suggestions waiting".
- Right: who and when, the person's optional message (`ht-quote`), editable name, category, description, intent and suggested starting goal.
- Actions: Approve & publish (primary), Save as draft (creates an unpublished catalog habit), Reject (danger, asks for an optional reason).
- Always state that publishing creates an independent catalog habit and does not touch the person's private data.
