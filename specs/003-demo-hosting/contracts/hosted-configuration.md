# Contract: hosted configuration

Where every value the hosted demo needs lives ([ADR 0015](../../../docs/adr/0015-demo-hosting.md), research
R-02, R-03). "Secret" follows the spec's boundary: passwords, connection strings, keys and tokens.

## Web app settings (Azure App Service)

| Key (app setting, `__` = `:`) | Secret | Set by | Read by | Value |
|---|---|---|---|---|
| connection string `HabitTracker` (type SQLAzure) | yes | provisioning script | host; workflow step 3 (masked) for the migration bundle | SQL authentication connection to the Basic database |
| `Operator__AdministratorEmail` | no, but kept out of the repository and masked in the run log | provisioning script (prompt; refused unless it ends in `@example.com`, HP-014) | host (ADR 0007); workflow step 3 (masked) for the smoke check | an `example.com` address |
| `Operator__AdministratorPassword` | yes | provisioning script (prompt) | host; workflow step 3 (masked) | — |
| `Operator__DemoPassword` | yes | provisioning script (prompt) | host; workflow step 3 (masked) | — |
| `DataProtection__KeysDirectory` | no | provisioning script | host (research R-07) | `/home/data-protection-keys` |
| `ASPNETCORE_FORWARDEDHEADERS_ENABLED` | no | provisioning script | framework (research R-08) | `true` |
| `Deployment__Commit` | no | workflow step 7 | workflow step 2; the Operator | the full SHA of the deployed commit, or empty during and after a failed step 7 |

The host reads the first five (and the framework the sixth). `Deployment__Commit` is not read by the app.
Local development keeps User Secrets for the `Operator:*` keys and has no `DataProtection:KeysDirectory`.

## SQL server

The server administrator password is generated by the provisioning script, given to Azure only through
`@<file>` arguments of the Azure CLI (research R-03) and stored nowhere else than in the connection string
above.

## GitHub environment `demo`

Variables only, none secret: `AZURE_CLIENT_ID`, `AZURE_TENANT_ID`, `AZURE_SUBSCRIPTION_ID`,
`AZURE_RESOURCE_GROUP`, `AZURE_WEBAPP_NAME`, `AZURE_SQL_SERVER`, `AZURE_SQL_DATABASE`, `DEMO_BASE_URL` (the
published `https://<app>.azurewebsites.net` address). The environment has no secrets: the workflow reads the
secret values from the web app at run time.

## Never

- No secret value in the repository, the workflow file, a command-line argument, the run log, the operator log
  or an error page (HP-007, SC-004).
- The administrator email does not appear in the repository or the run log (HP-015, masked).
